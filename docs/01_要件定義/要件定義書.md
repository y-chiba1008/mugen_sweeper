# 📝 「無限マインスイーパー」Web アプリ 要件定義書

## 🎯 1. 目的と概要

- **アプリ名称：** 無限マインスイーパー
- **コア目的：** ブラウザ上で進捗が永続化され、無限にプレイ可能なマインスイーパーを提供し、ユーザーの「コツコツとプレイしたい」ニーズに応える。
- **ターゲットユーザー：** 暇つぶしや動画を見ながらプレイしたい人、パズルゲーム愛好者。
- **差別化ポイント：** 進捗状況（盤面、得点、ライフ）が **IndexedDB** に永続的に保存されること。チャンク単位の差分保存により、無限盤面でも効率的にデータを保持する。

## 💻 2. 機能要件 (Functional Requirements)

| ID         | カテゴリ       | 要件（機能）                 | 詳細・備考                                                                                                                                 |
| :--------- | :------------- | :--------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- |
| **FR-100** | **盤面**       | **無限に広がる盤面**         | ユーザーの操作に応じて盤面を動的に生成・拡張する。表示範囲に応じてチャンク（16×16 マス単位）を遅延読み込みする。                         |
| **FR-101** | **操作**       | **盤面移動**                 | ユーザーはマウスドラッグによって盤面を移動できる。ドラッグとクリックを区別するため、一定距離以上の移動のみドラッグとして扱う。             |
| **FR-102** | **操作**       | **ズーム機能**               | ユーザーはマウスホイールで盤面の表示を拡大/縮小できる。倍率は **0.5 倍〜2.0 倍** の範囲に制限する。カーソル位置を基準にズームする。       |
| **FR-103** | **初期状態**   | **ゲーム開始時の状態**       | ズーム倍率 1.0 で開始し、原点 (0, 0) のセル（および隣接する空のセル）が開かれた状態で始まる。ビューは最後に操作したセルを中心に配置する。 |
| **FR-104** | **地雷配置**   | **地雷配置ロジック**         | 地雷の配置確率は**設定ファイル**（`src/config/gameConfig.ts`）で指定する。（初期値: **25%**）原点を含む周囲 9 マスには地雷を配置しない。   |
| **FR-105** | **スコア**     | **得点計算**                 | 開いたセル 1 つにつき 1 点加算する。フラグ設置による加点はない（コード操作で開いたセルは通常の開示と同様に加点する）。                   |
| **FR-106** | **ライフ**     | **初期ライフ設定**           | 初期ライフ数は**設定ファイル**で指定する。（初期値: **3 個**）                                                                             |
| **FR-107** | **ライフ**     | **ライフ消費**               | 地雷を踏んだ場合、ライフが 1 つ減る。                                                                                                      |
| **FR-108** | **ライフ**     | **ライフ回復**               | **設定ファイル**で指定した閾値（初期値: **1000 ポイントごと**）に到達するごとにライフが 1 つ追加される。                                 |
| **FR-109** | **ゲーム終了** | **ゲームオーバー**           | ライフが 0 になったらゲームオーバー。ゲームオーバー後は「リスタート」ボタンで新しいゲームを開始する（自動開始はしない）。                  |
| **FR-110** | **操作**       | **フラグ設置**               | 未開示セルを右クリックするとフラグを設置/解除できる。開示済みセルにはフラグを設置できない。                                                |
| **FR-111** | **操作**       | **コード操作**               | 開示済みの数字セルを左クリックすると、隣接セルのフラグ数と数字が一致する場合に未開示セルを自動開示する。残り未開示セルが地雷のみの場合は自動でフラグを設置する。 |
| **FR-112** | **永続化**     | **進捗の自動保存**           | スコア・ライフ・ハイスコア等のメタ情報と、盤面セル情報を **IndexedDB**（Dexie.js）に自動保存する。詳細は [db-design.md](./db-design.md) を参照。 |
| **FR-113** | **永続化**     | **保存トリガー**             | メタ情報はスコア・ライフ・ハイスコア・ゲームオーバー状態・現在地の変化時に保存する。盤面セルは開示時・フラグ操作時にチャンク単位で差分保存する。 |
| **FR-114** | **永続化**     | **セーブデータの再開**       | ブラウザ再起動後、互換性のあるセーブデータがあれば前回の進捗（ゲームオーバー状態を含む）から再開する。セーブデータのバージョンが一致しない場合は新規ゲームとして開始する。 |
| **FR-115** | **永続化**     | **現在地の記録**             | 最後に操作したセルの座標をメタ情報に保存し、次回起動時のビュー初期位置および「現在地へ移動」機能に利用する。                               |
| **FR-116** | **ハイスコア** | **ハイスコアの記録と更新**   | 過去の最高得点を IndexedDB に記録し、プレイ中に現在の得点が超えた場合、リアルタイムで値を更新する。リスタート時もハイスコアは引き継ぐ。   |
| **FR-117** | **ハイスコア** | **ハイスコア更新メッセージ** | ハイスコアを更新してゲームオーバーになった場合、「ハイスコア更新！」メッセージとアイコン（🎉）を表示する。                                 |
| **FR-118** | **UI**         | **主要情報の表示**           | 画面上部 HUD に「現在のスコア」「ハイスコア」「残りライフ数（❤ アイコン）」を常時表示する。ゲームオーバー時はメッセージとリスタートボタンを表示する。 |
| **FR-119** | **UI**         | **現在地へ移動**             | HUD のボタンから、最後に操作したセルへビューをスムーズにスクロールできる。                                                                 |

## ⚙️ 3. 非機能要件 (Non-Functional Requirements)

| ID          | カテゴリ           | 要件                 | 詳細・備考                                                                                                                                  |
| :---------- | :----------------- | :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------ |
| **NFR-100** | **パフォーマンス** | **応答性**           | 無限盤面の描画、移動、ズーム操作時にストレスのない快適な応答性を確保する。ビューポート内のセルのみ描画し、表示範囲のチャンクのみ読み込む。 |
| **NFR-101** | **保守性**         | **調整可能な設定**   | **地雷の確率、初期ライフ数、ライフ追加の閾値**の 3 項目を `src/config/gameConfig.ts` で容易に変更できるように実装する。                   |
| **NFR-102** | **セキュリティ**   | **データ整合性**     | セーブデータの `version` フィールドとアプリ側の `SAVE_DATA_VERSION`（初期値: `2.0.0`）を照合し、不一致の場合はセーブデータを破棄して新規ゲームを開始する。 |
| **NFR-200** | **技術環境**       | **技術スタック**     | **React 19** + **TypeScript** + **Vite** を用いたフロントエンド開発を行う。永続化には **Dexie.js**（IndexedDB ラッパー）を使用する。      |
| **NFR-201** | **動作環境**       | **対象環境**         | **PC ブラウザ**（モダンブラウザ）での動作に限定する。スマートフォン対応は考慮しない。                                                       |
| **NFR-300** | **デザイン**       | **モダンなデザイン** | **Tailwind CSS 4** および **Shadcn/UI** を採用し、視覚的に洗練されたモダンなデザインを実現する。アイコンには **Lucide React** を使用する。 |
| **NFR-301** | **UI/UX**          | **操作性**           | 盤面移動やズーム操作がスムーズに行えるよう、快適な操作性を確保する。ドラッグ操作直後の誤クリックを防止する。                                |
| **NFR-302** | **品質**           | **テスト**           | **Vitest** + **Testing Library** により、ゲームロジック・ストレージ・UI コンポーネントの単体テストを実施する。                              |
