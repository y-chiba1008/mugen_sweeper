# 🎮 無限マインスイーパー

ブラウザ上で進捗が永続化され、無限にプレイ可能なマインスイーパーゲームです。

## 📖 概要

**無限マインスイーパー**は、従来のマインスイーパーのコンセプトを拡張し、無限に広がる盤面でプレイできるWebアプリケーションです。ゲームの進捗状況（盤面、得点、ライフ）はブラウザのIndexedDBに自動保存されるため、いつでも中断した場所から再開できます。

### 主な特徴

- 🔄 **無限に広がる盤面**: ユーザーの操作に応じて動的に生成・拡張
- 💾 **進捗の自動保存**: IndexedDBによる永続的なデータ保存
- ❤️ **ライフシステム**: 地雷を踏んでも即座にゲームオーバーにはならない
- 🏆 **ハイスコア機能**: 最高得点を記録・表示
- 🗺️ **ミニマップ**: 読み込み済みの盤面全体をドット絵スタイルで俯瞰表示
- 🎨 **モダンなUI**: Tailwind CSSとShadcn/UIによる洗練されたデザイン

## ✨ 主要機能

### 盤面操作

- **無限に広がる盤面**: ユーザーの操作に応じて盤面を動的に生成・拡張
- **盤面移動**: マウスドラッグによって盤面を自由に移動
- **ズーム機能**: マウスホイールで盤面の表示を拡大/縮小
- **初期状態**: 最初のセル（および隣接する空のセル）が開かれた状態で開始

### ゲームシステム

- **地雷配置**: 地雷の配置確率は設定ファイルで指定可能（初期値: 25%）
- **得点計算**: 開いたセル1つにつき1点加算
- **ライフシステム**:
  - 初期ライフ数: 設定ファイルで指定可能（初期値: 3個）
  - 地雷を踏むとライフが1つ減る
  - 設定した閾値（初期値: 1000ポイントごと）に到達するごとにライフが1つ追加される
- **ゲームオーバー**: ライフが0になったらゲームオーバー。「リスタート」ボタンで新しいゲームを開始

### データ管理

- **自動保存**: 盤面情報、得点、残りライフをIndexedDBに自動保存
- **ハイスコア**: 過去の最高得点を記録・表示。更新時にリアルタイムで通知

### UI表示

- **主要情報の表示**: 画面上に「現在の得点」「ハイスコア」「残りライフ数」を常時表示
- **ミニマップ**: これまで読み込んだ盤面全体を俯瞰表示し、クリックでその場所へジャンプ

## 🛠️ 技術スタック

- **フレームワーク**: React 19
- **ビルドツール**: Vite
- **スタイリング**: Tailwind CSS 4
- **UIコンポーネント**: Shadcn/UI
- **言語**: TypeScript
- **アイコン**: Lucide React
- **永続化**: Dexie.js（IndexedDBラッパー）

## 📋 動作環境

- **対象環境**: PCブラウザ（モダンブラウザ）
- **注意**: スマートフォン対応は考慮していません

## 🚀 セットアップ

### 必要な環境

- Node.js
- pnpm

### インストール手順

1. リポジトリをクローン

```bash
git clone <repository-url>
cd mugen_sweeper
```

2. 依存関係をインストール

```bash
pnpm install
```

3. 開発サーバーを起動

```bash
pnpm dev
```

4. ブラウザで `http://localhost:5173` を開く

## 📦 ビルド

本番用のビルドを作成する場合:

```bash
pnpm build
```

ビルド結果は `dist` ディレクトリに出力されます。

プレビューを確認する場合:

```bash
pnpm preview
```

## ⚙️ 設定

以下の項目を設定ファイル（`src/config/gameConfig.ts`）で変更可能です:

- 地雷の配置確率（初期値: 25%）
- 初期ライフ数（初期値: 3個）
- ライフ追加の閾値（初期値: 1000ポイントごと）

## 🎮 使い方

1. **セルを開く**: 左クリックでセルを開きます
2. **フラグを立てる**: 右クリックでフラグを立てます
3. **盤面を移動**: マウスドラッグで盤面を移動します
4. **ズーム**: マウスホイールで拡大/縮小します
5. **ミニマップ**: HUDの「マップ」ボタンから盤面全体を確認し、クリックでその場所へジャンプできます
6. **進捗の保存**: 自動的にブラウザに保存されます
